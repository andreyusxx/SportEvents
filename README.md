# SportEvents

Навчальний проєкт з дисципліни «Конструювання програмного забезпечення». Варіант № 20: Реєстрація учасників і результати змагань.

## Склад рішення
- SportEvents.Core — логіка предметної області (бібліотека класів)
- SportEvents.App — консольний застосунок (введення, виведення)

## Вимоги
.NET SDK 8.0 або новіший (або .NET 10.0), Git.

## Складання та запуск
```bash
dotnet build
dotnet run --project SportEvents.App
```
## Стандарт кодування
Правила описано у файлі `CODING_STANDARD.md` і закріплено в `.editorconfig` та аналізаторах. Перевірка:
```bash
dotnet format --verify-no-changes
```
